# Manual de Identad Visual — AsisControl

## 1. Esencia de Marca

### Nombre de Marca
**AsisControl**

### Concepto Central
AsisControl representa control, validación, puntualidad y gestión inteligente de asistencia.

La identidad visual fusiona:
- ✔ Confirmación
- ⏱ Tiempo y seguimiento
- 👤 Presencia humana
- 📊 Control operativo empresarial

El isotipo combina una marca de verificación dominante con una composición circular inspirada en un reloj y una silueta humana abstracta.

# 4. Logo

## Construcción del Logo
### Elementos
1. Check principal
2. Composición circular tipo reloj
3. Punto humano minimalista
4. Wordmark “AsisControl”

## Versiones Permitidas
### Horizontal Principal
- Isotipo izquierda
- Texto derecha

### Isotipo
- Solo símbolo
- Uso para app, favicon y redes

### Vertical
- Símbolo arriba
- Texto abajo

---

# 5. Zona de Seguridad

Usar un margen mínimo equivalente al tamaño del punto superior del isotipo alrededor de todo el logo.

Nunca colocar elementos dentro de esta área.

---

# 6. Tamaños Mínimos

- Logo completo: 120px ancho mínimo
- Isotipo: 32px mínimo

## Impresión
