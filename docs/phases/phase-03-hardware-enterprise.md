# Fase 3 - Hardware y enterprise

Objetivo: llevar Asiscontrol a integraciones fisicas, clientes grandes y operacion de alta exigencia.

## Alcance

- Integracion con lectores de huella mediante SDK o puente local.
- Puente local para hardware.
- Torniquetes y controladoras de puerta.
- Reconocimiento facial donde sea legalmente permitido.
- Patrullaje movil avanzado.
- Bases dedicadas para clientes grandes.
- Dominios white-label.
- API externa para clientes enterprise.
- Deteccion de anomalias.
- Retencion y anonimizacion automatica.
- Migracion a alta disponibilidad.

## Entregables esperados

- Aplicacion local bridge firmada y versionada.
- Contratos de integracion por fabricante.
- Modelo de permisos para acciones fisicas.
- Auditoria reforzada de aperturas, rechazos y excepciones.
- Politicas legales para biometricos y reconocimiento facial.
- Arquitectura cloud o hibrida para alta disponibilidad.

## Riesgos

- Los navegadores no garantizan soporte universal para biometricos.
- Cada fabricante puede requerir SDK, licencia o driver distinto.
- Biometria requiere consentimiento, retencion, cifrado y controles legales mas fuertes.
- Control fisico de puertas necesita pruebas de seguridad antes de produccion.
